## 1. 名词

| 名词 | 是什么 |
|---|---|
| BBat | 方块图层：一组相对零点的格子，可以有多个图层；宿主 B 的 `BBat`（`link: blue_wool` flood fill，≤ 64 跨度）是它的前身 |
| LS（λ. 栏目答） | 可参数化的 BBat：列表式「选区替换」，可以重复出现、可以套娃，用**模式匹配 - 剪枝**防止无限套娃 |
| clawd（cd） | 按 Q 牵绳跟在玩家身后的小螃蟹 Ent，持有一个 LS 并提供编辑工具；Etoys Halo 在方块世界的兄弟 |
| 钻石箱 | 保存 cd 的容器。两个格子做检查点 / 查看器，右侧一排是「当前栏目答」；可嵌套，用 emoji 命名 |
| 参数 | LS 上可替换的槽：方块种类、颜色、子建筑有无。物品栏 Ctrl+1 代入参数 1 |

## 2. 创建与模式

- 创造模式：**Z 键**剪出（不按 Ctrl+Z 时创建 cd，否则退化成更简单的 BBat）。生存模式和 JS 代码里也能用 cd。
- 抠取：XRay 求差（导入档不支持 diff 时用「不接地测试」），抠出各种体积的建筑，cd 在面前刷出。
- 大建筑：先放出 cd，调好角度，用横纵激光切分 / 小地图（s03 §3.4 `gm.actOnMap.add`）鼠标切分出 "Subagents" 各自处理，完事点 cd 变钻石箱。

## 3. cd 的操作

| 部位 | 左键激活 · 右键退出 · 滚轮使用 |
|---|---|
| 左脚 | 切换移动 / 缩放 |
| 右脚 | 旋转（四向） |
| 头 | 上下滚 |
| 左手 | 往下滚，上滚最多回原位 |
| 左帽子 | 换块菜单（记住「快速换块菜单」） |
| 右帽子 | 查看器 UI（类似 Shulkr 的超平坦托盘；形状、参考线 / 切面渐变照 Structmatic） |

工具配色：**黄 = 缩放，绿 = 移动，橙 = 魔棒选取，紫 = 查看器 UI**。

cd 在身后时：右键是 paint，Shift + 右键是 place；左键默认是选区。选中后弹右键菜单：

- 移动、扩充并顺延尾部、参数化到 LS 上
- 选区组合：增选上次 / 从上次减选 / 矩选到上一点 / 设置选区（默认）
- 选区方式：只选视口中的 / 按方块类型选 / 选不接地的 / 魔棒（默认）
- 插件脚本（s07 模组可以注册菜单项）

## 4. LS 的编辑语义

- 在 LS 上放置的方块会修改 LS **及其所有实例**（L-1）。GCreat 模式 0 / 9 键「一键连到脚」的线段和面同样适用。
- cd 里可以单独保护 / 显隐一个子建筑；靠钻石箱派生（fork）或反查（XRay xref）。
- 在钻石箱里拖参数进去：cd 自己 fork 一份带进去，于是可以直接在箱里换块，同时与当前屋子解绑。
- cd 可执行：图层切分、缩容扩容（直线 BBat 平铺和单项变动）、拖动、四向旋转、装进刷怪蛋投掷、剪掉 / 存钻石箱 / 扔掉。
- 更激进的用法：收藏树、调池塘、圈地「打捞」整段地形储藏起来，用于在另一段平面里补间、调整和重新生成地表、群系或矿洞（与 s02 生成器的 `explain / knobs` 衔接）。

## 5. BBat → 动画实体

- mesher 要支持从 BBat 生成**可缩放 / 旋转、有原点**的多图层动画实体（比 kaalus 的锤子家具更进一步）。
- BBat 内部的**依存块**（`linkBlk`，s04 §3）天然构成一棵树 = 骨骼树。用 GCreat「只按深度透视选方块」的方法链接，再投影到控制点 UI / 图层 UI 编辑。
- 渲染走 s03 §4 的原生实体 pass（每个图层一根骨骼）。碰撞盒用 AABB，照矿车。
