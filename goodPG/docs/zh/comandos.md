# 命令手册

游戏内按 `T` 打开聊天，输入 `/` 开头即执行命令（按 `V` 语音、`B` 耳语）。所有命令名都有**中文别名**，西语原名和英语别名同样可用；大小写、重音、`_`/`-` 与空格不敏感，写错一两个字母会自动纠正，名字也可以只写前缀。

- `/帮助 [命令]` 查看全部命令或某条命令的用法。
- 参数里的中文名（物品、方块、生物、效果、附魔、结构）按 Minecraft 简体中文译名匹配；英文 `key`（如 `diamond`、`oak_log`）也可以用。
- 坐标支持 `~` 相对写法：`~`（当前位置）、`~1`、`~-2`。

## 玩法与状态

| 命令 | 别名 | 参数 | 说明 |
|---|---|---|---|
| `/模式` | `/modo`、`gamemode` | `生存`\|`创造`（也接受 `s`/`c`/`survival`/`creative`/`0`/`1`） | 切换自己的游戏模式 |
| `/难度` | `/dificultad`、`difficulty` | `和平`\|`简单`\|`普通`\|`困难`（也接受 `0-3`） | 修改世界难度 |
| `/首领` | `/jefes`、`bosses` | `自动`\|`原版`\|`强化` | 首领强化规则；不带参数显示当前值 |
| `/时间` | `/hora`、`time` | `白天`\|`正午`\|`日落`\|`黄昏`\|`夜晚`\|`深夜`\|`午夜`\|`日出`\|`黎明`\|`0-24000` | 修改一天中的时间，也可写 `/时间 set 夜晚` |
| `/杀死` | `/matar`、`kill` | 可选 `[生物]` | 不带参数立即死亡；带生物名清除 256 格内该生物 |
| `/传送` | `/tp` | `<玩家>` | 传送到另一名玩家身边（支持名字前缀） |
| `/列表` | `/lista`、`list` | — | 在线玩家 |
| `/种子` | `/semilla`、`seed` | — | 显示世界种子 |

## 给予与生成

| 命令 | 别名 | 参数 | 说明 |
|---|---|---|---|
| `/给予` | `/dar`、`give` | `<物品> [1-576]` | 物品掉在脚下；名称按中文名或 key 模糊匹配，例如 `/给予 钻石 5`、`/给予 diamond 5` |
| `/召唤` | `/invocar`、`summon` | `<生物> [充能]` | 在面前生成生物；`/召唤 闪电` 落雷，`/召唤 苦力怕 充能` 生成充能苦力怕 |
| `/效果` | `/efecto`、`effect` | `<效果> [秒] [等级]`，或 `清除` | 秒 1–3600，等级 1–5；`/效果 清除` 移除全部效果 |
| `/附魔` | `/encantar`、`enchant` | `<附魔> [等级]` | 作用于手上的物品，等级 1–10 |
| `/经验` | `/experiencia`、`xp` | `<数量> [点数\|等级]` | 默认给点数 |

## 世界与结构

| 命令 | 别名 | 参数 | 说明 |
|---|---|---|---|
| `/定位` | `/localizar`、`locate` | `<结构>` | 最近的同类结构坐标与距离；名称可用中文（`村庄`、`沙漠神殿`、`下界要塞`…）或西语别名 |
| `/维度` | `/dimension` | `<主世界\|下界\|末地> [x y z]` | 传送到另一维度（出生点或指定坐标） |
| `/放置方块` | `/setblock` | `<x> <y> <z> <方块>` | 放一个方块；坐标可用 `~` |
| `/填充` | `/fill` | `<x1> <y1> <z1> <x2> <y2> <z2> <方块>` | 填满长方体，最多 32768 块 |
| `/袭击` | `/asalto`、`raid` | — | 在 200 格内的村庄发动袭击（和平难度无效） |
| `/巡逻` | `/patrulla`、`patrol` | — | 在附近生成掠夺者巡逻队 |

## 语音

| 命令 | 别名 | 参数 | 说明 |
|---|---|---|---|
| `/语音` | `/voz` | `开启`\|`关闭`\|`静音 <玩家>`\|`取消静音 <玩家>`\|`音量 <玩家> <0-200>` | 不带参数显示当前状态与同世界开启语音的人 |
| `/组队` | `/grupo` | `[名称]`\|`退出` | 同组的人在任何距离都能互相听见 |

## 容错规则

1. **命令名**：先精确匹配，再匹配前缀，最后按编辑距离（≤1 个字符的短名，≤2～3 个字符的长名）自动纠正；实在找不到会给出“你是不是想用：/…”的提示。
2. **参数名**：物品/方块/生物/效果/附魔/结构都按 `key` 与中文显示名匹配，同样支持前缀与拼写纠正；匹配到多个时会列出前 5 个候选（显示中文名），写成更精确的名字即可。
3. **数字**：允许千分位逗号；坐标允许 `~`、`~1`、`~-2`。
4. **客户端命令**：`/传送`、`/语音`、`/组队` 由客户端直接处理，不经过服务器。
