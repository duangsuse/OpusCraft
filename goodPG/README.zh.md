# VoxelCraft

> 本文是 [README.md](README.md) 的简体中文版；西语原文为准。

**▶ 立即游玩：[voxelcraft.arturo97xd.workers.dev](https://voxelcraft.arturo97xd.workers.dev)** —— 和朋友们用
同一个世界名称（或分享邀请链接）即可一起游玩。

一款在浏览器中运行的 Minecraft 风格方块游戏，拥有 *shader pack* 级画面、完整的**生存**模式，以及基于
Cloudflare（Workers + Durable Objects）的实时多人联机。面向 PC（键盘与鼠标）设计。

- **程序化无限世界**：包含 Minecraft 主世界的 53 个生物群系（苍白之园除外）：五种温度的海洋（以及各自的
  深海）、河流（含冻河）、沙滩（含积雪沙滩）与石岸；平原（向日葵平原、雪原）、草甸、森林（繁花森林）、
  白桦森林（原始白桦森林）、黑森林、樱花树林、针叶林（积雪针叶林、原始松木针叶林，以及长着巨型云杉的
  原始云杉针叶林）、冰刺之地、沙漠、恶地（风蚀恶地，以及带烟囱状岩柱的繁茂恶地）、热带草原
  （热带高原、风袭热带草原）、丛林（稀疏丛林、竹林）、沼泽与红树林沼泽、蘑菇岛、
  风袭丘陵（沙砾丘陵、森林丘陵）、雪林、积雪山坡，以及冰封山峰、尖峭山峰与
  裸岩山峰；洞穴（长着发光浆果的繁茂洞穴、带钟乳石的溶洞、含水洞穴、深
  暗之域）、熔岩湖、紫晶洞，以及 Minecraft 的八种矿石（在 0 以下的深板岩中
  也有）。
- **Java 26.3 的洞穴**：噪声洞穴（带石柱的「奶酪」洞穴、2D 与 3D 的意大利面隧道、
  相互交错的细面条隧道，以及通向地表的入口）、含水层（拥有各自水位的地下湖，
  不同水位之间的岩石屏障，深处的熔岩湖，以及 y = −54 以下的熔岩）与雕刻器
  （带厅堂和峡谷的蠕虫洞穴），公式与参数均取自 26.3。
- **维度**（第 8 阶段，进行中）：**下界**，需通过用火点燃的黑曜石传送门
  到达（在内停留 4 秒；此处 1 格等于主世界 8 格）。其地形、生物群系与装饰
  均移植自 Java 26.3：由基岩地板与天花板围成的巨大黑石洞穴、
  熔岩海、隧道，以及五个生物群系——下界荒地、**绯红森林**与**诡异
  森林**（巨型菌、菌岩、菌索、下界苗、垂泪藤与缠怨藤、菌光
  体）、**灵魂沙峡谷**（灵魂沙与灵魂土、玄武岩柱、灵魂火）和**玄武岩
  三角洲**（玄武岩柱、黑石、边缘环绕岩浆块的熔岩池）——每个都有自己的
  雾、粒子、音效与音乐。熔岩流得更快更远，水会
  蒸发，床会爆炸，指南针和时钟会乱转。绯红木与诡异木、
  黑石、玄武岩与下界砖及其所有形态。每个维度都是独立的世界
  （各自的存档、生物与系统）；在那里死亡会回到主世界。
- **下界生物**：**猪灵**崇拜黄金并以物易物（使用 Java 的交换表），
  如果你身上没带金质物品或去翻它们的箱子就会发怒，它们会猎杀疣猪兽并在获胜时跳舞；**猪灵
  蛮兵**；成组被激怒的中立**僵尸猪灵**；火球可被一击打回的**恶魂**；
  **烈焰人**；会分裂的**岩浆怪**；会冲撞并把目标顶飞的**疣猪兽**
  （可用绯红菌繁殖）和**僵尸疣猪兽**；能行走于熔岩之上、可用鞍和
  诡异菌钓竿骑乘的**炽足兽**；以及**凋灵骷髅**。离开下界的猪灵
  和疣猪兽会僵尸化。随之而来的还有火焰弹、光灵箭、
  灵魂疾行、《Tears》唱片、凋灵骷髅头颅和猪灵的头。
- **下界结构**（移植自 Java 26.3）：**下界要塞**——下界砖砌成，有横跨
  熔岩海的桥、走廊、带烈焰人刷怪笼的王座、阳台，以及种植下界疣的
  培育室（下界疣现在可种在灵魂沙上并生长）；四种**堡垒遗迹**
  （住房、疣猪兽棚、桥与藏宝室及其熔岩瀑布），
  像 Java 里那样逐块拼装，有猪灵、猪灵蛮兵与疣猪兽看守，还有堡垒的
  箱子（《Pigstep》唱片与猪鼻旗帜图案）；灵魂沙峡谷中的骨骼**化石**
  以及下界的**废弃传送门**，有时半沉在熔岩里。熔岩海有
  会冷却并缓慢漂移的硬壳，而不是重复的同一块贴图。
- **末地**（移植自 Java 26.3）：带图书馆与传送门房间的**要塞**，飞向
  最近要塞的**末影之眼**，以及用十二只眼睛开启的**末地传送门**；龙的
  主岛及其黑曜石柱和水晶，拥有全部阶段、首领血条的**末影龙**，
  其死亡表现（返回传送门、龙蛋与末地折跃门）以及用四颗水晶完成的**重生**（使用
  `/首领 困难（/jefes duros）`，或在困难难度下，每名玩家都会让它增加生命值，最后还会狂暴）；外
  岛与**紫颂植株**，带塔、桥、箱子和**潜影贝**的**末地城**，以及载着
  一柄**龙首**与**鞘翅**的**末地船**（按 Java 的物理滑翔，
  可用烟花火箭，飞行时有风）；能收纳自身内容的 17 色**潜影盒**，以及每名玩家各自的**末影
  箱**。
- **凋灵**（移植自 Java 26.3）：用三个凋灵骷髅头颅摆在沙子或灵魂沙的
  T 形上召唤（任意朝向，横放亦可）；出生时无敌，随后成长并爆炸；三颗头各自
  选择目标并发射会爆炸、造成凋零的凋灵之首（蓝色头颅能炸到黑曜石）；
  半血时披上护甲（箭会被弹开），受到伤害时会破坏周围的方块。紫色血条会
  遮蔽天空，死亡掉落下界之星，受害者倒下的地方会长出**凋零玫瑰**（使用 `/首领 困难（/jefes duros）`
  时也会随玩家数量增加生命值，并在最后双倍射击）。
- **下界带来的东西**：**远古残骸**与**下界合金**（工具、盔甲和马
  铠，可在**锻造台**上由钻石升级而来，不惧火焰并能在熔岩中漂浮）、
  **重生锚**（用荧石充能，可在下界设置重生点）、
  **磁石**与磁石指针、带金字塔、彩色光束与各种能力的**信标**、
  **灵魂营火**、**气泡柱**（在灵魂沙上向上、在岩浆块上向下，连船
  也会被带动），以及**石英**方块。
- **带战利品的结构**：带刷怪笼的地牢；像 Java 那样逐块拼装的废弃矿井
  （泥土房间、带支架的通道、铁轨、蜘蛛网、双层交叉口、楼梯、带支柱或
  锁链的桥、运输矿车与洞穴蜘蛛刷怪笼；在恶地中是深色橡木的）、
  沙漠神殿与丛林神庙、沉船、废弃传送门、雪屋、沙漠水井、
  女巫小屋、化石、海底废墟与埋藏的宝藏、带守卫者的海底
  神殿、住着灾厄村民与被囚禁的悦灵的林地府邸，以及深暗之域中的远古
  城市。它们的箱子里装着 Minecraft 的战利品；`/定位（/localizar）` 会告诉你最近的一座在哪里，
  制图师还会出售探险家地图。
- **深暗之域**：位于山脉之下，附近有生物死亡时幽匿会蔓延，感测体会听见
  振动（并输出红石信号），还有尖啸体，以及从地下钻出、能嗅闻、
  追逐所闻之声并发出音爆的*监守者*。
- **天气**：雨、雪与带闪电的雷暴（闪光、雷声与伤害）。在寒冷地区，雪
  会层层堆积、水会结冰；靠近光源则会融化。
- **地图与指南针**：空地图会变成该区域的地图（128×128 格），拿在
  手上即可查看；指南针指向出生点。十种木头（橡木、白桦、云杉、丛林、金合欢、深色橡木、樱花、
  红树、苍白橡木与竹）。像如今的 Minecraft 一样高 384 格：
  从 y = −64（基岩）到 319。
- **主世界目录**（约 920 个方块和 1160 个物品，见 [`docs/cobertura.md`](docs/cobertura.md)）：
  16 种颜色（染料、羊毛、地毯、遇水硬化的混凝土、染色玻璃、
  带釉陶瓦、床、蜡烛与旗帜），所有石材的楼梯、台阶与墙，会
  氧化的铜（蜜脾可为它上蜡、斧头可刮除）及其工具和盔甲，
  珊瑚礁、海带林、海晶石与海绵、大型花、甜浆果、杜鹃与
  垂滴叶；花盆、灯笼、锁链、钟、脚手架、画与物品展示框；悬挂式
  告示牌、雕纹书架（可放入和取出书）、盔甲架、给生物命名的命名牌
  拴绳（拴玩家或栅栏）以及能在一个槽位里携带多种物品的收纳袋；
  新食物、52 种刷怪蛋、望远镜与时钟。还有打火石、弩、三叉戟、
  马铠与狼铠、烟花火箭、潮涌核心、生物头颅（含闪电苦力怕）、
  带 16 张原创音乐唱片的唱片机、可书写并在讲台上朗读的书、带图案的
  旗帜（织布机）、炼药锅、细雪、会弹跳的黏液块，以及此前缺失的各种地板。
- **生存**：生命值、饥饿与饱和度、水下氧气、摔落、熔岩、火焰、
  溺水、虚空与窒息伤害，生命恢复，死亡掉落物品栏并重生。
  挖掘有基于方块硬度和工具的真实耗时（带裂纹），工具
  会磨损，还有食物、弓与箭、水桶与熔岩桶。
- **物品栏与合成**：36 格物品栏带 2×2 合成，3×3 工作台，
  箱子与熔炉在玩家之间共享。单击、右键、Shift + 单击、数字键 1–9 和 Q
  的作用都与 Minecraft 一致。
- **62 种生物**，具备 AI、寻路（A*）、动画与各自的音效：农场
  与野生动物（狐狸、山羊、北极熊、兔子、狼、熊猫、鹦鹉、犰狳，以及带
  蜂巢和蜂蜜的蜜蜂）、水生生物（鱼、海豚、海龟、美西螈、青蛙、发光
  鱿鱼、守卫者）和怪物（僵尸、骷髅、苦力怕、蜘蛛、末影人、溺尸、女巫、
  史莱姆、幻翼、蠹虫与僵尸村民）。还有蝙蝠、豹猫、哞菇、悦灵、
  行商羊驼以及骷髅马（闪电陷阱）与僵尸马。怪物在
  黑暗中生成，亡灵会在阳光下燃烧。
- **村庄与交易**：村民按工作站点方块分为 13 种职业（包括牧师），按生物群系分为 7 种
  类型（衣服与部分交易不同），白天游荡、夜晚回家；右键打开
  采用 Minecraft 26.3 交易表的交易界面（每级多 2 项，共 5 级）。价格随需求上涨，
  并随你在每个村民那里的声望（村民之间会互相转告）以及村庄英雄而变化；它们会在工作站点方块上
  补货。还有流浪商人和保护村庄的铁傀儡。
- **掠夺者与袭击**：掠夺者前哨站和带队长的巡逻队。队长的不祥之瓶会给予
  不祥之兆，进入村庄后便会以波次的形式发动袭击（掠夺者、卫道士、
  带尖牙与恼鬼的唤魔者、劫掠兽与女巫），顶部有进度条；打赢它你便成为
  村庄英雄。唤魔者会掉落不死图腾。
- **驯服与骑乘**：狼和猫可以驯服（会坐下、跟随并保护主人）；
  铁傀儡和雪傀儡用南瓜建造。马、驴、骡与骆驼可以驯服
  并用鞍骑乘（蓄力跳跃）；羊驼会吐口水。
- **流动的水与熔岩**：与 Minecraft 一样：水蔓延 7 格、熔岩 3 格，会下落，会寻找
  最近的空隙，移走水源后会干涸，两个水源会产生第三个水源，水
  与熔岩接触会形成黑曜石、圆石或石头。水流会拖拽玩家，
  水面在着色器中会倾斜并流动。
- **造型建造**：木头、圆石、石头、石砖、砖块与砂岩的台阶（也有双台阶）
  和楼梯；栅栏和栅栏门会自动连接；带合页的双格门
  （以及双开门）、活板门、用来攀爬的梯子、玻璃板和
  墙上的火把。放置方式与 Minecraft 相同（是上半砖还是下半砖、朝向如何取决于你
  点击的位置和视线方向），有真实的碰撞箱，上台阶和楼梯不用跳。
  还有 8 种石头的墙（像栅栏那样连接）以及立在地上或墙上的告示牌：放下时
  会输入文字（四行），所有玩家都能看到。
- **床**：8 种颜色的床：夜里睡觉时，如果世界中所有玩家
  都躺下了就会跳到黎明（附近有怪物则不行），床会成为你的重生点。
- **工作方块**：可拼成 54 格大箱子的箱子；烟熏炉（食物）与
  高炉（矿石），速度是熔炉的两倍；营火会发光、冒烟、最多同时
  烤四份食物，踩上去会烧伤；切石机用来制作台阶、楼梯、墙和砖块。
- **农业**：锄与耕地（4 格内的水或雨水会滋润它，会变干，
  跳上去会踩实）；从草里得到的种子；按 Minecraft 速度生长的小麦、胡萝卜、马铃薯与
  甜菜根；骨粉；面包、烤马铃薯、糖、
  干草捆与蛋糕（按份食用，并返还桶）。南瓜与西瓜：它们的
  茎成熟后会在旁边结果；南瓜可用剪刀雕刻（可插火把、灯笼），
  并在世界中成组生成。堆肥桶会把作物残渣变成骨粉。
- **钓鱼**：带浮漂和鱼线的钓鱼竿；鱼上钩时浮漂会下沉，必须及时
  收竿：鳕鱼、鲑鱼、热带鱼、河豚、一些垃圾，偶尔还有宝藏。
- **农场动物**：动物会跟着拿着它们食物的人，并可繁殖（爱心粒子，幼崽
  20 分钟长大，吃东西会更快）；羊可以剪毛，吃草后羊毛会重新长出
  来；牛可以用桶挤奶，鸡会下蛋，蛋可以投掷
  （有时会孵出小鸡）。
- **盔甲**：皮革、铁、金与钻石（头盔、胸甲、护腿与靴子），减伤
  与耐久同 Minecraft；右键穿上或放进物品栏的槽位，会显示在
  玩家身上（也显示在其他玩家身上），并在 HUD 上有护甲条。
- **盾牌**：按住右键举起，会减慢移动，并挡下正面（而非背后）
  袭来的攻击、箭与爆炸；每次重击都会磨损它。
- **状态效果**：33 种 Minecraft 效果（速度、力量、生命恢复、中毒、
  隐身、跳跃提升、缓降、急迫、反胃、失明、发光、飘浮、
  凋零……），有其机制、图标与 HUD 上的剩余时间。它们来自
  药水、食物（金苹果、河豚、按花的种类决定的迷之炖菜）、对
  掠夺者敲响的钟，以及游泳时的海豚；牛奶可以清除它们。
- **药水**：支持用烈焰粉酿造药水，以及 42 种使用 Minecraft
  配方的药水；可以喝、投掷、留下滞留云，还能涂在箭上。
- **附魔**：带书架的附魔台、主世界的 37 种附魔
  （效果真实生效）、附魔书、铁砧（合并、修复与重命名）与砂轮；
  被附魔的物品会发光。
- **红石与机关**：红石粉、红石火把、中继器、比较器、拉杆、按钮、压力板、
  红石灯、阳光探测器、音符盒、绊线、铁门与
  铜灯；活塞与黏性活塞（用黏液块和蜂蜜块）、侦测器、漏斗、发射器、投掷器，以及
  爆炸效果与 Minecraft 相同的 TNT。见 [`docs/redstone.md`](docs/redstone.md) 与
  [`docs/mecanismos.md`](docs/mecanismos.md)。
- **船与矿车**：10 种木头的船与筏（也有带箱子的），带桨；普通
  铁轨、动力铁轨、探测铁轨与激活铁轨；运输矿车、动力矿车、漏斗矿车与 TNT 矿车。
- **经验**：击杀生物、繁殖动物、开采矿石和从熔炉取出产物时掉落经验球；
  等级使用 Minecraft 的公式，HUD 上有等级条，死亡时会掉落一部分。
- **活的世界**：沙子和沙砾会下落，植物和火把需要支撑，砍树时
  树叶会掉落，树苗会长成树，草会蔓延，仙人掌与
  甘蔗会生长。
- **自研粒子**（最多 16000 个，用程序化图集绘制）：会升腾并被风
  吹走的烟、动画火焰、火花、闪光、爱心、会弹跳的方块
  碎屑、带火光的爆炸、从天花板滴落并溅开的水滴、气泡、熔岩余烬、
  菌丝孢子、晴朗夜晚的萤火虫、雨水飞溅，以及摇曳着落下
  并停在地面的花瓣和树叶。它们会与几何体柔和地融合。
- **高级图形**（WebGL2，全部自研）：
  - 具备大气散射的物理天空（Hillaire 模型）：日出、日落、有月相
    与星星的夜晚。
  - 太阳与月亮的柔和阴影（扭曲阴影贴图 + PCF），生物
    与物品也有阴影。
  - 多次散射的体积云，以及云在地面上的阴影。
  - 体积光（*god rays*），水下也有。
  - 带折射、随深度物理吸收、屏幕空间反射（SSR）、
    太阳高光、岸边泡沫、焦散，以及地平线上无限海洋的水。
  - PBR 材质（法线、粗糙度、金属度、自发光），树叶与
    植物的次表面散射，植被随风摆动，火把照明与环境光遮蔽。
  - TAA、泛光、自动曝光（视线适应）、ACES 色调映射与夜视。
  - 由代码生成的原创 16×16 像素画贴图（600 多张方块贴图、
    物品与全部生物；不含 Mojang 的任何资源）。
- **多人联机**：分享世界链接。每个世界都是一个 Durable Object，运行
  游戏服务器（有玩家在线时每秒 20 tick），并把改动、箱子与熔炉、
  每名玩家的状态以及动物保存到 SQLite。
- **空间语音**：语音直接在浏览器之间传输（WebRTC；服务器只
  让玩家互相发现），并像世界中的另一种声音那样播放：从说话者的头部发出，随
  距离衰减直到 48 格（耳语时 24 格），墙壁会按材质削弱它（羊毛
  几乎完全挡住，玻璃和树叶削弱得少），在洞穴和房间里会有回响，水下听起来发闷，
  且只能听到同一维度的人。按键说话（V）或说话时自动开启的麦克风、按玩家
  调节音量或静音，以及在任何距离都能听见的**小队**（`/组队（/grupo）`）。
- **离线单人**：同一个游戏服务器运行在 Web Worker 中，世界保存在
  浏览器里（IndexedDB）。可通过菜单中的复选框启用，或在无法
  连接服务器时自动启用。
- **程序化音效**（Web Audio）：按材质的脚步声、破坏/放置与挖掘声、每种
  生物的声音、战斗、进食、弓、爆炸、附近的水与熔岩、低血量时的心跳、
  环境音（风、鸟、蟋蟀、洞穴、岸边、水下）以及生成式音乐。

### 生存入门

1. 空手破坏原木，把它们做成木板（物品栏，2×2 网格）。
2. 用 4 块木板做一个工作台；在它上面制作木棍、木镐和木剑。
3. 用镐采集圆石，制作石制工具和一个熔炉（8 块圆石）。
4. 用煤炭熔炼铁矿石得到铁锭（铁制工具、桶、
   剪刀）。钻石需要铁镐。
5. 夜晚来临前，制作火把（煤炭 + 木棍）和一个庇护所：怪物不会在
   明亮的地方生成。

内置配方：木板、木棍、工作台、火把、箱子、熔炉、书架、石砖、
砂岩、砖块、黏土、全部 20 种工具（木、石、铁、金、
钻石 × 镐、斧、锹、剑）、桶、剪刀、弓、箭、纸、书、铁/金/钻石块
（以及还原成锭）、羊毛和用花或青金石染色的羊毛、台阶、
楼梯、栅栏、栅栏门、门、活板门、梯子、玻璃板、床、锄、
面包、干草捆、骨粉、糖和蛋糕。熔炉里可以烧：玻璃、石头、金属锭、木炭、
砖块、陶瓦、熟肉和烤马铃薯。

## 本地开发

要求：Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

打开 `http://localhost:5173`。Vite 的开发服务器也会运行 Worker 和
Durable Object（借助 `workerd`），因此多人联机在本地就能用：用同一个世界
打开两个标签页即可测试。

其他命令：

```bash
npm run typecheck   # 类型检查（客户端、服务端与测试）
npm test            # 游戏服务器测试（流体、生物、放置、床、农业、id...）
npm run build       # 把客户端 + Worker 编译到 dist/
npm run preview     # 编译并在本地提供生产版本
```

命令的完整清单、中文别名与容错规则见 [docs/zh/comandos.md](docs/zh/comandos.md)。

### 静态托管（不跑服务器）

`npm run build` 会把客户端留在 `dist/client/`，它是纯静态文件，可以直接丢给任何静态服务器（`nginx`、`http-server`、GitHub Pages…）：

```bash
npx http-server goodPG/dist/client -p 8080   # 然后把站点根目录指向 dist/client
```

如果像本仓库一样把**项目目录**整个交给静态服务器，也可以直接访问 `http://host/goodPG/`：`index.html` 会发现没有 Vite 并自动加载 `dist/client` 里的构建（因此构建文件名是固定的 `assets/index.js`、`assets/index.css`，见 `vite.config.ts`）。

静态托管下只有**单机**可用（世界跑在 Web Worker 里，存档在 IndexedDB）；联机需要 Worker（Cloudflare 或本地 `wrangler dev`）。

## 部署到 Cloudflare

1. 在 [Cloudflare](https://dash.cloudflare.com/sign-up) 创建一个免费账户。
2. 从终端登录：

   ```bash
   npx wrangler login
   ```

3. 部署：

   ```bash
   npm run deploy
   ```

   Wrangler 会显示公开 URL（例如 `https://voxelcraft.<你的子域名>.workers.dev`）。
   首次部署会创建带 SQLite 存储的 Durable Object `GameWorld`（免费套餐已
   包含）。用旧版本创建的世界仍可继续使用：其中的建筑都会
   保留。

4. 在游戏中分享邀请链接（菜单或暂停菜单中的**复制邀请**）。
   形如 `https://…/?mundo=nombre-del-mundo`：所有用同一世界名称进入的人都
   一起游玩。菜单中选择的游戏模式会在创建新世界时应用；之后加入的
   玩家以该世界的模式开始。

### 免费套餐的限制

游戏面向 Workers 免费套餐下的朋友小团体：

- **服务器时间**：只要有玩家在线，世界的 Durable Object 就按每秒 20
  tick 模拟（4 名玩家和上百只生物时每 tick 消耗 1–2 ms CPU）。免费套餐
  每天包含 13000 GB·s，大约相当于**每天 28 小时的世界活跃时间**（所有
  世界合计）。最后一名玩家离开后模拟会停止，不再消耗。
- **请求**：传入消息按 20:1 计费；在约 8 Hz 的位置更新（仅在你
  移动时）和每 5 秒一次的 ping 下，每个玩家小时大约消耗 1500–2500 次，而每日额度是 10 万
  次请求。
- **写入**：世界每 30 秒保存一次（每个改动过的区块、每个箱子以及
  每名玩家各一行），最后一名玩家离开时也会保存，因此流动的水或生长的草不会
  耗尽每天 10 万行的额度。
- 服务器负责给编辑排序：如果两名玩家同时触碰同一个方块，所有人
  看到的结果一致；断线期间你所建造的内容会在重连时发送。
- 每个世界最多 16 名玩家。

如果团队较大或游玩时间很长，Workers 付费套餐（5 美元/月）可以消除这些
顾虑。

### 尚未包含的内容

VoxelCraft 复刻了 Minecraft 的核心生存循环，但并非整个游戏：

- Minecraft 的 86 种生物中已实现 73 种：缺少凋灵以及 2024–2026 年的那些（sniffer、breeze、creaking……）。
- 没有凋灵（下界之星只能在创造模式获得），离开末地时也没有末地诗。
- 每名玩家的物品栏和生命值由其浏览器管理（朋友之间的信任）：方块、
  箱子、熔炉、生物和掉落物由服务器控制。
- 流体、生物和植物生长只在玩家附近（约 64 格）模拟，类似 Minecraft
  的「模拟距离」。
- 如果服务器在没有玩家在线时重启，掉落物和怪物不会被保存（动物、
  箱子和建筑会）。

## 部署到自己的 VPS（open-compute）

也可以在装有 [open-compute](https://open-compute.dev) 的 VPS 上运行整套服务（网页、
多人联机和已保存的世界）——这是一个兼容 Cloudflare Workers、可在单台
机器上运行的平台。分步指南（安装、带 HTTPS 的域名、更新与备份）见
[docs/despliegue-vps.md](docs/despliegue-vps.md)；简要版：

```bash
curl -fsSL https://open-compute.dev/install.sh | sudo sh && sudo ocd setup --system --yes
git clone https://github.com/EijunnN/minecraft-clone.git voxelcraft && cd voxelcraft && npm ci
npm run deploy:vps
```

## 画质

**设置**中有四档预设（低、中、高、极致）以及各项独立控制：视距、
分辨率缩放、阴影、云、反射、体积光、TAA 与泛光。游戏会根据检测到的 GPU
选择初始预设。如果笔记本上卡顿，试试**低**或降低分辨率
缩放。

## 目录结构

```
src/
  shared/          方块、物品、生物、配方、容器、协议与世界生成
    sim/           游戏服务器：流体、生物（AI、A*）、物理、物品、熔炉、存档
      server/      服务器系统（systems.ts 负责创建并连接；messageRouter.ts 分发消息）
  server/          Worker + Durable Object（GameWorld），带 SQLite 存储
  client/
    world/         光照与网格化（Web Worker）、区块管理
    render/        WebGL2 管线与着色器（天空、地形、水、云、生物、物品、后期）
    textures/      程序化贴图（方块、物品与生物）
    audio/         程序化音效引擎
    game/          游戏循环、玩家、生存、物品栏、实体、输入
    net/           网络客户端与本地服务器（Web Worker + IndexedDB）
    ui/            菜单、HUD、物品栏、合成、箱子与熔炉界面
```
